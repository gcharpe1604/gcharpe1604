## About

I am a Computer Science student building developer tools, backend systems, and full-stack applications.

I currently focus on Go, cloud-native engineering, distributed systems, and open source. I am open to software engineering internships, mentorship programs, and meaningful technical collaborations.

## Open Source

### CNCF Harbor CLI

I contribute to the Go-based CLI for [Harbor](https://github.com/goharbor/harbor), a CNCF cloud-native registry project.

My contributions include:

* login flag validation and safer credential guidance,
* CLI error propagation across configuration and interactive flows,
* ongoing work on the `harbor gc history` command with API integration, filtering, pagination, tests, and documentation.

[View Harbor CLI contributions →](https://github.com/goharbor/harbor-cli/pulls?q=is%3Apr+author%3Agcharpe1604)

I have also contributed merged fixes and improvements to [Sugar Labs Music Blocks](https://github.com/sugarlabs/musicblocks/pulls?q=is%3Apr+author%3Agcharpe1604) and active UI and TypeScript work to [Jaeger UI](https://github.com/jaegertracing/jaeger-ui/pulls?q=is%3Apr+author%3Agcharpe1604).

## Featured Work

### GitAnalyzer

A developer tool that analyzes GitHub commit history, scores commit-message quality, identifies repository-wide patterns, and suggests practical improvements.

* Rule-based quality scoring and repository insights
* AI-assisted commit rewriting with provider fallback
* GitHub API integration
* Supabase authentication and analysis history

**Stack:** React, TypeScript, Vite, Supabase and GitHub REST API

[Live Demo](https://gitanalyzer-ai.netlify.app/) · [Source Code](https://github.com/gcharpe1604/gitanalyzer)

### OpenTrack

A full-stack application for tracking open-source contributions, repositories, pull requests, and contributor activity in one place.

**Stack:** React, Node.js, Express and PostgreSQL

[Source Code](https://github.com/gcharpe1604/opentrack)
